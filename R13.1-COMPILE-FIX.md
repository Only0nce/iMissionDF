# R13.1 Compile Fix

This revision preserves R13 runtime behavior and only fixes Qt5/GCC compilation issues in `CrashDiagnostics.cpp`.

## Fixes

1. Renamed local array `signals` to `fatalSignals` because Qt5 defines `signals` as a macro expanding to `Q_SIGNALS` / `public`.
2. Cast Linux `pid_t` / `long` thread IDs to `qlonglong` before `QByteArray::number()` to avoid overload ambiguity on aarch64.
3. Cast pointer values to `qulonglong` for deterministic hexadecimal logging across LP64 targets.

No diagnostic timing, crash handler behavior, frequency logic, codec logic, QML, audio logic, or recorder behavior was changed.
