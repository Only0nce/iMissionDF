# R20.4-SPECTRUM-CUDA1.2-STICKY-METRICS

## Scope

This revision is derived surgically from `R20.4-SPECTRUM-CUDA1.1-FPS60` and changes only the Spectrum measurement-HUD presentation in `SpectrumGLPlot.qml`.

No C++, CUDA, FFT cadence, Waterfall compute, Audio, Network, 5G, Recorder, AstraRX protocol, frequency ownership, Peak Scan, project-file, or resource-file behavior is changed.

## Requested UX

The PEAK / NOISE / SNR metrics are no longer a fixed top-left HUD. They are physically attached to the currently selected listening/receiver band.

Behavior:

- The HUD follows the selected receiver band continuously during tune, drag, zoom, pan, or backend receiver updates.
- Default placement is to the right of the selection band.
- If there is insufficient safe space on the right, it flips to the left.
- If the selection returns near the left edge, it flips back to the right when enough space is available.
- A 16 px hysteresis prevents left/right flicker around the flip threshold.
- The existing Zoom-control footprint is reserved when deciding whether the right side has enough room.
- The panel background is translucent by default (`0.28`).
- The `LOCK` toggle changes only the panel presentation opacity to `1.0`; it does not freeze RF tuning or measurements.
- Only the LOCK button consumes pointer input. The remaining HUD area does not add a new MouseArea, preserving the existing click/drag-to-tune gesture underneath.

## Data / Stability Contract

The native C++ metrics remain unchanged:

- `peakDb`
- `peakFrequencyHz`
- `noiseFloorDb`
- `snrDb`

No FFT-sized data is reintroduced into QML. The CUDA1.1 FPS60 rendering/compute path remains unchanged.

## Runtime file changed

- `SpectrumGLPlot.qml`

## Validation focus

1. Tune/drag the receiver bar across the screen; HUD must remain attached.
2. Move close to the right edge; HUD must flip to the left before clipping/Zoom overlap.
3. Move close to the left edge; HUD must return to the right.
4. Hover/drag around the flip threshold; HUD must not chatter left/right.
5. Toggle `LOCK`; background must switch translucent <-> opaque while metrics keep updating.
6. Click/drag anywhere on the HUD except the LOCK button; existing tuning interaction must remain available.
7. Confirm Spectrum/Waterfall FPS and CUDA telemetry remain identical to CUDA1.1 behavior.
