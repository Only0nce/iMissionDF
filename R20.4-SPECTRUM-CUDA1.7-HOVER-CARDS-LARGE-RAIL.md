# R20.4-SPECTRUM-CUDA1.7-HOVER-CARDS-LARGE-RAIL

## Scope
UI-only refinement derived from CUDA1.6. No C++, CUDA, FFT, audio, network, receiver, or backend behavior is changed.

## Changes
- Bottom Waterfall HUD cards remain individual translucent gray cards.
- Idle card background stays at ~30% opacity.
- Hover increases gray-card opacity to ~62%, increases border visibility, and adds a subtle 1.2-1.8% scale lift.
- Card transitions use short OutCubic animations (160-180 ms) so the HUD feels less rigid.
- Text, fields, slider, meter, and tick content remain fully opaque.
- SCAN/MEMORY right-rail launcher grows to 96 px wide and 108 px total height (~52 px per button plus spacing).
- SCAN/MEMORY receive hover/press color + scale animation while preserving existing toggle logic.
- Larger launcher stays right-aligned with the Waterfall legend and remains inside the reserved Waterfall utility rail.

## Preserved
- Spectrum 42% / Waterfall 58%.
- Floating Scan/Memory workspace and folder drill-down.
- Sticky Peak/Noise/SNR metrics.
- Persistent Waterfall history.
- CUDA plugin ABI and CUDA worker.
- 60 FPS presentation path.
- AstraRX/WebSocket/frequency/audio/network/5G behavior.

## Target test
1. Hover each bottom HUD card: background should smoothly become clearer without dimming/changing its text.
2. Move off the card: it should smoothly return to the idle translucent gray.
3. Hover/press SCAN and MEMORY: button should animate smoothly and remain easy to hit.
4. Verify SCAN toggles floating Scan workspace, repeated SCAN closes it, and MEMORY switches modes.
5. Check the larger right rail does not overlap the Waterfall legend or bottom HUD at target resolution.
