# R20.4-SPECTRUM-CUDA1.21-SPECTRUM-DIVIDER-UX

## Goal
Make the Spectrum/Waterfall height control obvious and easy to operate on mouse and touch displays, while enlarging the Waterfall Pause/Clear controls. Preserve the CUDA/FPS60 path, RF calibration, manual Intensity scale behavior, Waterfall history, tuning gestures, Scan/Memory workspace, and the unrelated application bottom-menu handle.

## Runtime scope
Only `SpectrumGLPlot.qml` changes.

## Spectrum / Waterfall divider
- Replaces the fixed read-only `spectrumRatio` with an operator-adjustable state.
- Default split remains 42% Spectrum / 58% Waterfall.
- Limits: Spectrum 25% minimum, 72% maximum.
- Adds a dedicated divider at the exact Spectrum/Waterfall boundary.
- Visible handle: 110 x 32 px rounded pill.
- Interaction target: 280 x 58 px for easier mouse/touch grabbing.
- Vertical-resize cursor on desktop.
- Drag events are coalesced through a 16 ms timer to avoid excessive native `FftDisplayItem` resize churn.
- Release applies the final ratio immediately.
- No automatic process changes `spectrumRatio`; the operator is authoritative.

## Waterfall actions
- Pause/Resume: 96 x 40 px.
- Clear: 88 x 40 px.
- 12 px bold uppercase labels.
- Hover/pressed feedback added without animation-heavy effects.
- Right margin keeps the actions clear of the Waterfall legend rail.

## Preserved behavior
- Manual/locked Intensity scale from CUDA1.20.
- Spectrum and Waterfall still use the existing Intensity Min/Max behavior.
- RF calibration and Y-axis semantics unchanged.
- Spectrum click/drag-to-tune remains unchanged outside the divider hit target.
- Waterfall Pause preserves history; Clear discards history exactly as before.
- CUDA worker/plugin/kernel unchanged.
- Bottom application menu/power handle unchanged.
- Scan/Memory/floating workspace unchanged.

## Startup marker
```
[R20.4-SPECTRUM-CUDA1.21-SPECTRUM-DIVIDER-UX] adjustableSplit=1 defaultRatio=0.42 minRatio=0.25 maxRatio=0.72 dividerHit=280x58 pause=96x40 clear=88x40
```

## Target validation
1. Start: split is 42/58.
2. Drag divider down: Spectrum grows and Waterfall shrinks smoothly.
3. Drag divider up: Spectrum shrinks and Waterfall grows smoothly.
4. Clamp at 25% and 72% Spectrum.
5. Stop dragging: split remains fixed; it must not move by itself.
6. Spectrum tuning works outside the divider hit target.
7. Waterfall history remains persistent during divider dragging.
8. Pause/Resume is easy to hit and does not clear history.
9. Clear remains the only action that explicitly clears Waterfall history.
10. Intensity Min/Max sliders remain fully adjustable and manually locked.
