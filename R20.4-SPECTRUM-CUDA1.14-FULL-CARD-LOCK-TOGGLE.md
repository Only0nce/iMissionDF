# R20.4-SPECTRUM-CUDA1.14-FULL-CARD-LOCK-TOGGLE

## Scope

This revision is a QML-only interaction change derived directly from `R20.4-SPECTRUM-CUDA1.13-GREEN-SPECTRUM-RED-MAXHOLD`.

Only `SpectrumGLPlot.qml` changes at runtime.

## Requested behavior

The Peak / Noise / SNR measurement card attached to the selected receiver band is now one large touch/click target.

- Tap anywhere inside the metrics card -> toggle lock state.
- Unlocked -> existing translucent panel opacity remains.
- Locked -> existing 100% panel opacity remains.
- The `LOCK` / `LOCKED` badge remains visible as status feedback, but it is no longer a separate input target.
- Sticky selection-band attachment and left/right auto-flip behavior are unchanged.
- Metrics continue updating while locked; lock controls panel opacity only.

## Input ownership

A single `MouseArea` now covers the complete metrics overlay. This avoids nested click handlers and accidental double toggles when the old small LOCK target is pressed.

The full-card MouseArea intentionally owns pointer presses that begin inside the metrics HUD. The rest of the Spectrum retains the existing click/drag-to-tune behavior.

## Unchanged

No changes were made to:

- `FftDisplayItem.cpp/.h`
- CUDA kernels, worker, plugin ABI, or backend selection
- FFT cadence / FPS60 presentation
- Spectrum green fill / red Max Hold visual renderer
- Waterfall processing / persistent history
- Floating Scan / Memory workspace
- Audio / ALSA
- Network / 5G
- Frequency ownership / tuning algorithm

## Runtime marker

```text
[R20.4-SPECTRUM-CUDA1.14-FULL-CARD-LOCK-TOGGLE] fullMetricsMouseArea=1 lockBadgeVisualOnly=1
```

## Target validation

1. Tap PEAK text -> card toggles locked/unlocked.
2. Tap NOISE text -> toggles.
3. Tap SNR text -> toggles.
4. Tap empty area inside card -> toggles.
5. Tap LOCK / LOCKED badge -> toggles exactly once.
6. Drag/tune outside the card -> existing Spectrum interaction remains unchanged.
7. Move selected receiver to left/right edges -> sticky HUD auto-flip remains unchanged.
