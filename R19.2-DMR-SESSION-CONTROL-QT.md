# R19.2 Qt DMR Session Control

- DMR selector exposes Slot 1 / Slot 2 / Both.
- `dmrSlotFilter` is used by live dspcontrol and new presets/current receiver state.
- AstraRX `type=digital_voice` messages are parsed by WebSocketClient and bridged through Mainwindows to QML.
- `dmrActiveSlot` is updated from AstraRX and shown in the DMR mode selector.
