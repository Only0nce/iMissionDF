# R20.4-SPECTRUM-CUDA1.11-SPECTRUM-VISUAL-POLISH

## Scope
Visual-only Spectrum polish derived from CUDA1.10. No DSP, FFT cadence, CUDA, Waterfall, frequency, audio, network, scan/memory logic, or backend behavior changes.

## Changes
- Live Spectrum trace: dedicated bright cyan-teal `#49F3DD`.
- Max Hold trace: dedicated amber-gold `#FFBE4A`.
- Live Spectrum line width: 1.35 px.
- Max Hold line width: 1.15 px.
- Live Spectrum area fill: restrained vertical cyan/teal gradient, alpha 58 -> 32 -> 6.
- Round line joins/caps improve readability without multi-pass glow.
- Dedicated QML trace colors avoid changing the existing analyzer accent used by selection/HUD components.

## Performance policy
The renderer still uses a single filled polygon pass and one live polyline pass. No blur, shadow, multi-pass glow, additional timers, JavaScript FFT processing, or CUDA synchronization was introduced.

## Expected result
The live RF trace is easier to distinguish from the grid and Max Hold, while the translucent fill adds hierarchy without obscuring RF details or the selection overlay.
