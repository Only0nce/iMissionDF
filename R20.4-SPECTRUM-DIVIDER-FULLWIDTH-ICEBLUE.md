# R20.4 Spectrum Divider Full-Width Ice Blue

## Scope

This revision is intentionally limited to the draggable separator between Spectrum and Waterfall in `SpectrumGLPlot.qml`.

No Radio-page redesign, renderer rewrite, CUDA change, FFT change, backend change, Scan/Memory change, or other UI layout change is included.

## Final divider UX

The divider is now treated as the separator itself rather than a button:

- visible separator spans the full analyzer width,
- the complete separator has an invisible 56 px vertical hit area,
- direct drag starts immediately; no hold/unlock step,
- no pill/background button,
- no `DRAG` text,
- center symbol uses down-arrow + six dots + up-arrow,
- center symbol enlarged to `64 x 44 px`,
- Ice Blue/Cyan manipulation palette shared semantically with PAN,
- subtle 100–110 ms hover/drag color/opacity transition only.

## Color contract

- idle line: `#5FAFC4`
- hover line: `#7DE3F3`
- drag line/symbol: `#D8FAFF`
- center symbol: `#8ED5E0`

Spectrum and Max Hold colors remain unchanged.

## Geometry and behavior preserved

- default Spectrum split: `0.42`
- minimum Spectrum split: `0.25`
- maximum Spectrum split: `0.72`
- resize event coalescing: `16 ms`
- Ice Blue PAN control: unchanged
- PAN height: `44 px`
- Spectrum/Waterfall lockstep renderer: unchanged
- CUDA path: unchanged
- Waterfall history: unchanged

## Interaction

```text
Spectrum
──────────────────────────────  ↓  ──────────────────────────────
                              • • • • • •
──────────────────────────────  ↑  ──────────────────────────────
Waterfall
```

Press/touch anywhere along the full separator hit area, move vertically, then release. The final split remains at the released position and is clamped to the existing 25–72% limits.

## Runtime file changed

```text
SpectrumGLPlot.qml
```

## Build impact

`SpectrumGLPlot.qml` is embedded in `qml.qrc`, so rebuild the main `iScanMR10` application. No CUDA-plugin rebuild is required.
