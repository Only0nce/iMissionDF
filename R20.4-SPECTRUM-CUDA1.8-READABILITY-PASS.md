# R20.4-SPECTRUM-CUDA1.8-READABILITY-PASS

## Scope

This revision is a QML-only readability pass derived from `R20.4-SPECTRUM-CUDA1.7-HOVER-CARDS-LARGE-RAIL`.
It does not change FFT, CUDA, WebSocket, receiver tuning, floating workspace behavior, waterfall history, audio, network, 5G, or backend ownership.

## Problem observed on target

The live Waterfall can become very bright cyan/green/yellow. CUDA1.7 used light translucent gray HUD cards, so the dynamic Waterfall could reduce effective contrast and make labels, numeric values, meter ticks, and Scan/Memory controls difficult to read.

## Changes

### Stable contrast HUD cards

Idle cards now use dark-neutral glass instead of light gray:

- idle background: ~72% dark neutral
- hover background: ~86% dark neutral
- idle border: low-opacity blue-gray
- hover border: higher-contrast teal/blue-gray
- hover animation remains smooth and does not alter child text opacity

### Explicit text hierarchy

- primary values: `#F4FBFF`
- secondary labels: `#D3E1E7`
- active/accent: `#6EF2E8`

The text is no longer dependent on the current Material foreground color for the three bottom HUD controls.

### Bandwidth control

- Low/High labels use explicit secondary text color.
- Numeric TextFields use explicit high-contrast white text.
- TextFields receive a small dark field background and subtle border.
- Numeric/value fonts are slightly larger/bolder.

### S-meter

- tick labels are brighter.
- value label is brighter.
- a one-pixel dark shadow is drawn behind tick/value text for contrast on dynamic Waterfall imagery.

### Intensity scale

- Min/Max values use explicit white text and bold weight.
- title uses explicit high-contrast text.
- Material accent updated to the local analyzer cyan.

### Waterfall legend

- legend shell background is darker and more opaque.
- Max/Mid/Min/dBFS labels are larger, bolder, and use explicit primary/secondary colors.

### Scan / Memory right rail

- idle background is substantially darker (~84% opaque).
- hover background becomes ~94% opaque.
- active mode uses stronger teal.
- borders have more contrast.
- label font sizes increased to 14/13 px.
- existing hover/press scale animation and toggle behavior are preserved.

## Unchanged behavior

- Spectrum 42% / Waterfall 58%
- CUDA1.1 FPS60 cadence
- CUDA plugin ABI/kernel/worker
- persistent full-axis Waterfall history
- Floating Scan/Memory workspace
- Sticky Peak/Noise/SNR selection metrics
- Scan/Memory toggle semantics
- RF tuning / frequency ownership
- audio / ALSA
- network / WiFi / 5G

## Target verification

On target, test with both dark-blue and bright green/yellow Waterfall states. Verify:

1. Low/High/Bandwidth text is readable without hover.
2. Max Hold label is readable without hover.
3. S-meter tick labels and value are readable.
4. Min/Max Intensity values are readable.
5. Scan/Memory text remains clear over bright Waterfall.
6. Hover transitions remain smooth.
7. Floating workspace behavior is unchanged.
8. Spectrum/Waterfall FPS and CUDA telemetry are unchanged from CUDA1.7.
