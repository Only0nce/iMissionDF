# R20.4 Reconciled Latest — 2026-09-14

## Why this revision exists

The supplied `src.tar(20260914-031359).xz` was not uniformly old or uniformly new. Inspection showed a mixed tree:

- LAN Phase A files were newer and must be preserved.
- Spectrum/Waterfall divider code had reverted to the older HOLD-3s implementation even though the repository already contained documentation for the later full-width direct-drag fix.
- The FBO edge fix was not present in source yet.
- Runtime hardening documentation existed, but several corresponding code changes were absent.

Blindly replacing the whole repository with an earlier "latest" source snapshot would therefore regress the newer LAN work again. This revision uses the user's uploaded tree as the authoritative base and restores only the missing latest revisions.
