# R20.4 Spectrum Divider Full-Width Hit Fix

## Scope

This is a surgical follow-up to the full-width Ice Blue divider revision. Runtime changes are restricted to `SpectrumGLPlot.qml`.

## Problems observed on hardware

1. The visible separator spanned the analyzer, but resize interaction was effectively usable only around the center symbol.
2. A dark/black strip was visible directly behind the center arrows/dots.
3. An unwanted color artifact was visible at the far-left separator edge.

## Fix

### Full-width interaction ownership

The divider now has a dedicated topmost `MouseArea` independent from the center glyph:

- `x = 0`
- `width = root.width`
- `height = 48 px`
- `z = 1000`
- immediate drag on press

The hit strip is biased upward into the Spectrum by 40 px and extends only 8 px into the Waterfall. This keeps the Waterfall `PAUSE` / `CLEAR` controls reachable while making the separator draggable from edge to edge.

### Remove black center mask

The old `dividerLineMask` rectangle is removed completely.

Instead, the separator is rendered as two bounded line segments:

```text
left edge -----------------    ↓    ----------------- right edge
                              ••••••
                               ↑
```

The center gap is transparent. There is no black rectangle, pill, button, or backing card behind the symbol.

### Remove left-edge artifact

Both line segments are explicitly bounded inside the analyzer:

- left segment begins at exactly `x = 0`
- right segment starts after the center-symbol gap
- right width is clamped with `Math.max(0, parent.width - x)`

No visual rectangle extends beyond the analyzer width.

## Preserved behavior

- immediate drag; no hold
- symbol size and arrows/dots concept
- Ice Blue palette
- 16 ms divider resize coalescing
- default split 42%
- split limits 25%–72%
- Spectrum/Waterfall renderer
- CUDA worker/plugin
- persistent Waterfall history
- PAN/zoom
- RF metrics
- Scan/Memory
- Radio page design

## Build impact

Only embedded QML changed. Rebuild the main application; do not rebuild the CUDA plugin.

```bash
qmake iScanMR10.pro -spec linux-jetson-orin-g++
make -j$(nproc)
```

## Hardware test

Test presses at five horizontal positions on the separator: far left, 25%, center, 75%, and far right. Every position must begin a vertical resize immediately. Confirm the center black strip and far-left artifact are gone, then verify Pause/Clear remain fully clickable.
