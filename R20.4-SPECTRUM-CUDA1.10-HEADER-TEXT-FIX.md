# R20.4-SPECTRUM-CUDA1.10 — Floating Workspace Header Text Fix

## Scope
This revision is derived surgically from CUDA1.9 and changes only the Floating Workspace header text layout in `SpectrumGLPlot.qml`.

## Problem
The workspace title (`SCAN WORKSPACE` / `MEMORY WORKSPACE`) and the `SPECTRUM + WATERFALL LIVE` badge used independent hard-coded horizontal positions. With real font metrics the two labels could overlap.

## Fix
- Give the workspace title an explicit id and content-driven width.
- Anchor the LIVE badge to `floatingWorkspaceTitleText.right` with a fixed 12 px gap.
- Add single-line/elide protection to both title and badge text.
- Preserve the existing header height, colors, panel geometry, close button, workspace content, CUDA/FPS60 pipeline, and backend behavior.

## Runtime files changed
- `SpectrumGLPlot.qml` only.

## Not changed
CUDA, FFT, FftDisplayItem, Waterfall history, Floating Workspace size, Scan/Memory folder logic, scrollbar geometry, Audio, Network, 5G, WebSocket, frequency control.
