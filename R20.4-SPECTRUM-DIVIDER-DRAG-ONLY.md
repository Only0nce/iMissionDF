# R20.4 Spectrum Divider — Drag Only

## Scope

Source baseline: user-provided `POP.tar(2).xz`.

This revision deliberately does **not** redesign the Radio page, Spectrum, Waterfall, PAN, controls, colors, layout, or backend behavior. Runtime code changes are restricted to `SpectrumGLPlot.qml` and only change the Spectrum/Waterfall divider interaction.

## Behavior change

Previous behavior:

`press -> hold 3 s -> unlock -> drag -> release -> lock`

New behavior:

`press -> drag immediately -> release`

The existing 16 ms resize coalescing remains active so high-rate pointer/touch events do not cause unbounded native renderer resize requests.

## Preserved contracts

- Spectrum default split: `0.42`
- Spectrum minimum split: `0.25`
- Spectrum maximum split: `0.72`
- Existing divider location and dimensions
- Existing amber divider palette
- Existing Ice Blue PAN palette and PAN behavior
- Spectrum/Waterfall renderer paths
- FFT/CUDA path
- Persistent Waterfall history
- Intensity scale
- Scan/Memory workspaces
- Frequency tuning behavior
- Radio page layout and design

## UI semantic adjustment

The stale `HOLD 3s` text/progress indicator is removed because there is no longer a hold gesture. The existing divider body remains in the same location, size, palette, and z-order and displays `DRAG` while preserving the surrounding design.

## Files changed

- `SpectrumGLPlot.qml`

No C++ or CUDA source is changed.

## Build

The QML file is embedded through `qml.qrc`, so rebuild the main application:

```bash
qmake iScanMR10.pro -spec linux-jetson-orin-g++
make -j$(nproc)
```

No CUDA plugin rebuild is required.

## Runtime validation

1. Start Radio page.
2. Press divider briefly without moving: analyzer split should remain effectively unchanged.
3. Press divider and move vertically immediately: Spectrum/Waterfall split must follow without waiting.
4. Drag to top limit: ratio clamps at 25%.
5. Drag to bottom limit: ratio clamps at 72%.
6. Release: split remains at final position.
7. Verify PAN/zoom/frequency tuning still work.
8. Verify Waterfall history is not cleared by divider resize.
