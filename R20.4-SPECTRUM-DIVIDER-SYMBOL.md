# R20.4-SPECTRUM-DIVIDER-SYMBOL

## Scope

This revision intentionally changes only the Spectrum/Waterfall divider interaction/visual in `SpectrumGLPlot.qml`.

The Radio page layout, theme, controls, Spectrum renderer, Waterfall renderer, CUDA worker/plugin, PAN control, intensity controls, Scan/Memory workspace, backend control path, and other project pages are unchanged.

## User-requested change

Replace the previous visible divider button/pill (`DRAG`) with a compact symbol matching the supplied reference:

- downward arrow above the separator,
- six small horizontal dots,
- upward arrow below the separator,
- no button/pill background,
- no text label,
- immediate vertical drag; no hold gesture.

The visual glyph is intentionally small (`48 x 34 px`) while the invisible drag hit area remains large (`300 x 66 px`) for reliable mouse/touch use.

## Interaction contract

```text
Press divider hit area
        |
        v
Immediate vertical drag
        |
        v
16 ms coalesced spectrumRatio update
        |
        v
Release -> final ratio applied
```

Preserved split constraints:

```text
default = 0.42
min     = 0.25
max     = 0.72
```

## Visual behavior

The divider line remains in its existing amber family. A small center mask prevents the separator line from visually connecting the six dots. The symbol itself uses the existing divider accent colors and becomes slightly stronger on hover/drag.

There is no new image resource and no `qml.qrc` change; the symbol is drawn using the existing Qt Quick `Canvas` in `SpectrumGLPlot.qml`.

## Files changed

Runtime source:

```text
SpectrumGLPlot.qml
```

No C++ or CUDA file changed.

## Build impact

`SpectrumGLPlot.qml` is embedded in the application QRC, so rebuild the main `iScanMR10` application. The CUDA plugin does not need to be rebuilt.

## Validation status

Static/source validation is performed in this package. Jetson Qt 5.15.2 target compilation is not claimed because the target toolchain is not available in the packaging environment.
