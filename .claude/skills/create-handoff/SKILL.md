description: Create an evidence-based handoff containing exact changes, validation, risks, rollback, and next commands.
---

# Procedure

1. Record branch, base, status, and intended scope.
2. List exact files created, modified, deleted, and intentionally untouched.
3. Summarize behavior preserved and intentionally changed.
4. List exact commands and results for static checks, builds, tests, runtime,
   target, and hardware validation.
5. List secrets/privacy review, generated artifacts, and cleanup needs.
6. Provide rollback and the next safe command.
7. Do not claim unperformed validation.

# Required Output

## Change Summary
## Repository State
## Files
## Validation Performed
## Validation Not Performed
## Risks and Decisions
## Rollback
## Next Steps
