# Purpose

Build a source-verified project map before planning or implementation.

# Procedure

1. Determine the repository root, current branch, upstream, worktrees, and status.
2. Read `CLAUDE.md`, `AGENTS.md`, and relevant docs.
3. Verify the build system from tracked manifests.
4. Locate entry points, qmake source lists, resources, C++/QML bridges, threads,
   protocols, persistence, and hardware boundaries relevant to the task.
5. Verify documentation claims against source.
6. Do not modify, stage, switch, or clean files.

# Required Output

## Scope
## Repository State
## Verified Architecture
## Relevant Code Paths
## Interfaces and Contracts
## Risks and Unknowns
## Recommended Next Step
