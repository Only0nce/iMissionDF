# Purpose

Establish a verified and safe starting state.

# Procedure

1. Resolve the repository root.
2. Inspect branch, upstream, ahead/behind state, and worktrees.
3. Inspect staged, unstaged, deleted, untracked, and relevant ignored files.
4. Inspect recent commits and candidate integration branches without switching.
5. Determine the authoritative tracked build manifest.
6. Identify user work that must be preserved.
7. Do not modify files or Git state.

# Required Output

## Repository State
## Branch and Upstream
## Local Changes
## Build System
## Recent Work
## Safety Assessment
## Recommended Next Action
