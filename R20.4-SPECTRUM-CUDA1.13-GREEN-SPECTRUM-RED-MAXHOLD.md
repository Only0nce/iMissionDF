# R20.4-SPECTRUM-CUDA1.13-GREEN-SPECTRUM-RED-MAXHOLD

## Scope

This revision is a visual-only Spectrum renderer refinement derived directly from
`R20.4-SPECTRUM-CUDA1.12-AARONIA-FILL`.

Runtime changes are limited to:

- `SpectrumGLPlot.qml`
- `FftDisplayItem.cpp`

No Waterfall, CUDA compute, FFT cadence, floating workspace, receiver-control,
audio, network, 5G, recorder, or frequency-ownership behavior is changed.

## Visual target

The live Spectrum uses a bright RF-instrument green presentation while Max Hold
uses red-orange for immediate historical/current separation.

- Live trace: `#B7FF3C`
- Max Hold: `#FF3B2F`
- Live fill: lime -> vivid green -> green -> emerald -> dark green -> near-transparent

The fill is clipped by the real live-spectrum polygon and extends to the plot
baseline. It does not synthesize, smooth, or modify FFT values.

## Performance policy

The 60-FPS presentation path remains structurally unchanged:

1. one filled polygon pass,
2. one live-spectrum polyline pass,
3. one optional Max-Hold polyline pass.

No glow, blur, shadow, extra QPainter layer, CUDA synchronization, or additional
frame timer is introduced.

## Build

Rebuild `iScanMR10` in Qt Creator because `FftDisplayItem.cpp` and the QML
resource changed. The CUDA plugin does **not** need to be rebuilt because its
source and ABI are unchanged.
