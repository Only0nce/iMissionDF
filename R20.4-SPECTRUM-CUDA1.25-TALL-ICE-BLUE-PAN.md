# R20.4-SPECTRUM-CUDA1.25-TALL-ICE-BLUE-PAN

## Scope

CUDA1.25 is a small usability refinement of the Ice Blue zoom PAN navigator from CUDA1.24.
The operator reported that the existing PAN length was already suitable, but its 24 px height made the thumb difficult to acquire and drag. This revision increases only the vertical interaction geometry.

## Runtime file changed

- `SpectrumGLPlot.qml`

## Geometry change

| Element | CUDA1.24 | CUDA1.25 |
|---|---:|---:|
| PAN width | unchanged | unchanged |
| PAN panel height | 24 px | **44 px** |
| PAN track height | 16 px | **30 px** |
| Track vertical inset | 4 px | **7 px** |
| Panel radius | 7 px | 9 px |
| Track/thumb radius | 5 px | 7 px |
| PAN label font | 9 px | 10 px |

The thumb still fills the track vertically, so the actual draggable area is now substantially taller without changing horizontal travel or frequency mapping.

## Behavior preserved

- Ice Blue palette is unchanged.
- PAN width and horizontal location are unchanged.
- PAN remains close to the Spectrum/Waterfall divider.
- PAN appears only when `zoomFactor > 1.0001`.
- Idle opacity remains `0.28`.
- Hover/drag opacity remains `0.96`.
- Opacity animation remains `140 ms`.
- `viewPanRatio` and local-track travel calculations are unchanged.
- Divider hold remains 3 seconds.
- Divider remains amber.
- Spectrum/Waterfall split, Intensity Scale, RF calibration, Pause/Clear, Scan/Memory and CUDA paths are unchanged.

## Startup marker

```text
[R20.4-SPECTRUM-CUDA1.25-TALL-ICE-BLUE-PAN] dividerHoldMs=3000 panPalette=ice-blue panHeight=44 panTrackHeight=30 panIdleOpacity=0.28 panHoverOpacity=0.96
```

## Build impact

Rebuild the main `iScanMR10` application because `SpectrumGLPlot.qml` is packaged through QRC.
The CUDA plugin does **not** need to be rebuilt.

## Target validation

On Jetson/Qt 5.15.2:

1. Zoom in until PAN appears.
2. Confirm PAN width remains the same as CUDA1.24.
3. Confirm PAN is visibly taller and easier to acquire.
4. Hover PAN and verify opacity changes from subtle to high contrast.
5. Drag the Ice Blue thumb left/right and verify smooth horizontal panning.
6. Verify min/max pan travel and zoom reset remain unchanged.
7. Verify the amber divider still requires a 3-second hold.
8. Verify Waterfall history is preserved while zooming/panning.
