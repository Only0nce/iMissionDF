# R20.4-SPECTRUM-CUDA1.12-AARONIA-FILL

## Scope
Spectrum visual-only revision derived from CUDA1.11. The reference direction is the filled analyzer presentation shown by Aaronia/SPECTRAN: the live Spectrum has a clear colored body below the trace rather than only a faint translucent wash.

## Changes
- Replaced the restrained single-color teal fill with a **multi-stop amplitude-oriented vertical gradient** clipped to the live Spectrum polygon.
- High-level signal area: yellow -> yellow-green -> green.
- Mid-level area: green -> teal -> cyan.
- Low-level/noise-floor area: cyan -> blue -> deep blue/teal.
- Live trace changed to high-contrast mint-cyan `#72F7E8`, width 1.45 px.
- Max Hold changed to warm gold `#FFD05A`, width 1.20 px.
- Fill is intentionally much more visible than CUDA1.11 while retaining transparency so grid and selection overlays remain readable.

## Performance policy
The renderer still performs only:
1. one filled-polygon pass,
2. one live Spectrum polyline pass,
3. one Max Hold polyline pass when enabled.

No blur, glow, extra framebuffer, JavaScript FFT processing, CUDA synchronization, FFT cadence, or Waterfall logic was added. This keeps the FPS60 architecture unchanged.

## Data correctness
Only colors, alpha values and pen widths changed. FFT values, dB mapping, frequency mapping, Max Hold data and selection metrics are unchanged.
