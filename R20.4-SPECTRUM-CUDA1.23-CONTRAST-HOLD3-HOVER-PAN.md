# R20.4-SPECTRUM-CUDA1.23-CONTRAST-HOLD3-HOVER-PAN

## Scope

This revision is derived surgically from CUDA1.22. Runtime changes are limited to `SpectrumGLPlot.qml`.

## Goals

1. Reduce the divider safety hold from 5 seconds to 3 seconds.
2. Keep the one-gesture safety model: short tap/immediate drag must still not resize.
3. Give the divider a new high-contrast amber/orange palette that remains visible over both Spectrum and Waterfall backgrounds.
4. Make the zoom PAN navigator visually quiet when idle and strongly visible on hover/drag.
5. Give PAN a new high-contrast magenta/purple palette so it does not disappear into the blue Waterfall.
6. Preserve CUDA/FPS60, FFT, Waterfall history, RF calibration, Intensity Scale, Scan/Memory, Pause/Clear, and zoom/pan behavior.

## Divider safety state machine

```text
LOCKED
  |
  | pointer press
  v
HOLDING (3 s)
  |  - amber progress bar / countdown shown
  |  - no resize is permitted
  |  - >24 px movement cancels the hold
  |
  | 3 s continuous hold
  v
UNLOCKED / DRAG
  |  - pill displays DRAG
  |  - vertical pointer movement updates split ratio
  |
  | release/cancel
  v
LOCKED
```

The unlock applies to one pointer gesture only. A second resize requires another 3 second hold.

## Divider visual palette

The previous teal control blended into the existing analyzer colors. CUDA1.23 changes the divider to a warm amber/orange family:

- Idle fill: `#7A3B00`
- Hover fill: `#B85A00`
- Holding fill: `#D97706`
- Unlocked/DRAG fill: `#FF8A00`
- Border/divider line: `#FFD166`
- Hold progress: `#FFF0A8`

The 300 x 66 px hit target and 126 x 36 px visible pill are unchanged.

## PAN idle/hover behavior

The PAN navigator remains beside the Spectrum divider, but its complete control now fades instead of leaving an opaque bar over live RF data:

```text
not hovered / not dragging -> opacity 0.28
hovered / dragging         -> opacity 0.96
transition                  -> 140 ms
```

The old ten-second opacity timer was removed. Visibility is now deterministic and driven only by pointer interaction.

PAN uses a new magenta/purple family:

- Panel: `#2A0F35`
- Border: `#FF5AE0`
- Track: `#6D2B78`
- Viewport thumb: `#FF4FD8`
- Label: `#FFE5FB`

This is intentionally different from the blue/cyan Waterfall and green Spectrum trace.

## Preserved behavior

- Spectrum split default/min/max ratios remain 0.42 / 0.25 / 0.72.
- Divider resize remains coalesced by the existing 16 ms timer.
- Pre-unlock touch movement tolerance remains 24 px.
- PAN remains visible only while zoom factor is greater than 1.
- PAN still updates `viewPanRatio` using the same local-track calculation.
- Manual/locked Intensity Scale behavior from CUDA1.20 is unchanged.
- Pause remains 96 x 40 px; Clear remains 88 x 40 px.
- Waterfall history is not cleared by resize or pan.
- CUDA plugin/kernel/worker and all C++ sources are unchanged.

## Target validation

On Jetson/Qt 5.15.2 verify:

1. Short click on divider does not resize.
2. Hold less than 3 seconds and release: no resize.
3. Hold continuously for 3 seconds: label changes to `DRAG`.
4. Drag after unlock: Spectrum/Waterfall split changes; release re-locks it.
5. Divider is visually distinct in idle, hover, hold and DRAG states.
6. Zoom in: PAN appears near the divider with low idle opacity.
7. Move pointer over PAN: whole navigator becomes strongly visible immediately/smoothly.
8. Move pointer away: PAN returns to low opacity.
9. Drag PAN thumb while hovered: horizontal pan remains functional and high-opacity.
10. Verify Intensity Scale, Pause/Clear, tuning, Waterfall persistence, Scan/Memory and application bottom menu are unchanged.
